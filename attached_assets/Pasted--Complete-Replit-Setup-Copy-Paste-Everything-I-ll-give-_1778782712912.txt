### **FILE 2: main.py**

**Copy-paste this exactly:**

```python
from flask import Flask, render_template, request, jsonify
import anthropic
import os
from dotenv import load_dotenv

load_dotenv()

app = Flask(__name__)

# Initialize Anthropic client
api_key = os.getenv('ANTHROPIC_API_KEY')
if not api_key:
    api_key = "sk-"  # You'll add real key later

client = anthropic.Anthropic(api_key=api_key)

@app.route('/')
def index():
    return render_template('form.html')

@app.route('/generate', methods=['POST'])
def generate_contract():
    try:
        data = request.json
        
        # Build the prompt for Claude
        prompt = f"""أنت متخصص قانوني أردني خبير في صياغة عقود العمل.

اكتب عقد عمل احترافي بالعربية يتوافق 100% مع القانون الأردني رقم 8 لسنة 1996.

البيانات:
- صاحب العمل: {data.get('employer_name', 'غير محدد')}
- الموظف: {data.get('employee_name', 'غير محدد')}
- المسمى الوظيفي: {data.get('job_title', 'غير محدد')}
- الراتب الشهري: {data.get('monthly_salary', '0')} دينار أردني
- تاريخ البدء: {data.get('start_date', 'غير محدد')}
- نوع التعاقد: {data.get('employment_type', 'دائم')}

اكتب العقد كاملاً بصيغة رسمية قانونية احترافية.

تأكد من تضمين:
1. اسم الأطراف والمعلومات الأساسية
2. تفاصيل الراتب والمزايا
3. ساعات العمل (8 ساعات يومياً)
4. الإجازات السنوية (14 يوم حسب القانون الأردني)
5. الإجازات المرضية (حسب القانون)
6. بنود الإنهاء والفصل
7. التزامات الطرفين
8. التوقيعات والتاريخ

ابدأ مباشرة بالعقد بدون مقدمات."""

        # Call Claude API
        message = client.messages.create(
            model="claude-opus-4-20250514",
            max_tokens=2500,
            messages=[
                {
                    "role": "user",
                    "content": prompt
                }
            ]
        )
        
        contract_text = message.content[0].text
        
        return jsonify({
            "success": True,
            "contract": contract_text
        })
    
    except Exception as e:
        return jsonify({
            "success": False,
            "error": str(e)
        }), 500

@app.route('/health')
def health():
    return jsonify({"status": "ok"})

if __name__ == '__main__':
    app.run(host='0.0.0.0', port=3000, debug=True)
```

## **TROUBLESHOOTING**

### **Error: "API Key Invalid"**
- Make sure you copied the full key (starts with `sk-`)
- Make sure you added it to Replit Secrets correctly
- Restart Replit (click Run again)

### **Error: "Module not found"**
- Click Run again, wait for installation to complete

### **Takes too long to generate**
- Normal! Claude takes 30-60 seconds
- Don't refresh the page
- Wait patiently

### **Form doesn't load**
- Check browser console (F12)
- Make sure Replit is running (green Run button)
- Try refreshing the page
