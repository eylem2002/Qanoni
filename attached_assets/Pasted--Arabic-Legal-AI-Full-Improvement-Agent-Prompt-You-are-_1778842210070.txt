**File:** `artifacts/legal-ai/src/pages/Home.tsx`

**Problem:** The current `handleDownloadPdf` function uses `window.open` + `window.print()`.

printer settings. Replace it with a real client-side PDF library.

**Steps:**

1. Install `pdfmake` in the frontend:
   ```
   cd artifacts/legal-ai && npm install pdfmake @types/pdfmake
   ```

2. Replace the entire `handleDownloadPdf` function with this logic:
   - Import pdfmake: `import pdfMake from 'pdfmake/build/pdfmake'` and `import pdfFonts from 'pdfmake/build/vfs_fonts'`
   - Set `pdfMake.vfs = pdfFonts.pdfMake.vfs`
   - Build a `TDocumentDefinitions` object with:
     - `pageSize: 'A4'`
     - `pageMargins: [40, 60, 40, 60]`
     - `defaultStyle: { font: 'Roboto', fontSize: 11, lineHeight: 1.8, alignment: 'right', direction: 'rtl' }`

     - The contract text as a `{ text: generatedContract, ... }` content block

   - Call `pdfMake.createPdf(docDefinition).download('عقد-عمل-' + employeeName + '.pdf')`

3. Update the download button label from `تحميل PDF` to `تحميل PDF ↓`
