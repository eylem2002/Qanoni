## **PHASE 1: CRITICAL ADDITIONS (PRIORITY 1) - IMPLEMENT FIRST**

### **Add These Fields to Your Form (Week 1-2)**

#### **1. Employee ID / Passport Number**
```
Field Name: رقم الهوية / جواز السفر (Employee ID / Passport)
Type: Text Input
Required: YES (mandatory per Article 15 of Labor Law)
Placeholder: "123456789"
Help Text: "رقم الهوية الوطنية أو رقم جواز السفر للعاملين غير الأردنيين"
Jordanian Law Reference: Article 15 - عقود العمل يجب أن تتضمن بيانات الهوية
Validation: 
  - Min 6 characters
  - Max 20 characters
  - Can be numeric only
Position: After "اسم الموظف" field
```

#### **2. Employer Registration Number (رقم التسجيل)**
```
Field Name: رقم التسجيل التجاري (Company Registration Number)
Type: Text Input
Required: YES (mandatory per Article 8 of Labor Law)
Placeholder: "12345678"
Help Text: "رقم التسجيل التجاري للشركة لدى وزارة الصناعة والتجارة"
Jordanian Law Reference: Article 8 - صاحب العمل يجب أن يرسل إشعار يتضمن بيانات الشركة
Validation:
  - Numeric only
  - 8 digits typically for Jordan
Position: After "اسم صاحب العمل" field
```

#### **3. Probation Period (فترة التجربة)**
```
Field Name: فترة التجربة (Probation Period)
Type: Number Input with Dropdown
Required: NO (optional - only if applicable)
Options:
  - "بدون فترة تجربة" (No probation)
  - "30 يوم" (30 days)
  - "60 يوم" (60 days)
  - "90 يوم" (90 days) - DEFAULT/RECOMMENDED
  - "مخصص" (Custom)
Help Text: "لا تزيد على 3 أشهر بموجب المادة 35 من قانون العمل"
Jordanian Law Reference: Article 35 - فترة التجربة لا تزيد على ثلاثة أشهر
Validation:
  - Max 90 days
  - Must be positive number
Position: After "نوع العقد" field
```

#### **4. Notice Period (فترة الإشعار)**
```
Field Name: فترة الإشعار (Notice Period)
Type: Dropdown
Required: YES
Default Value: "شهر واحد" (1 month)
Options:
  - "أسبوع واحد" (1 week)
  - "شهر واحد" (1 month) - DEFAULT (Article 23)
  - "شهرين" (2 months)
  - "مخصص" (Custom)
Help Text: "الحد الأدنى شهر واحد بموجب المادة 23 من قانون العمل"
Jordanian Law Reference: Article 23 - إشعار خطي قبل شهر واحد على الأقل
Position: After "نوع العقد" field (after Probation Period)
Display in Contract: 
  - "يترتب على أي من الطرفين إخطار الطرف الآخر خطياً برغبته في إنهاء العقد قبل [فترة الإشعار] على الأقل"
```

#### **5. Add Law References to Contract Output**
```
When generating contract, automatically include:

Article 23 Reference:
"بموجب المادة 23 من قانون العمل الأردني رقم 8 لسنة 1996"

Article 35 Reference (if probation exists):
"بموجب المادة 35 من قانون العمل الأردني رقم 8 لسنة 1996"

Article 28 Reference (termination):
"بموجب المادة 28 من قانون العمل الأردني رقم 8 لسنة 1996"
```

```

Display in Contract:
"تحدد حقوق الملكية الفكرية بموجب المادة 20 من قانون العمل الأردني"

Jordanian Law Reference: Article 20 - حقوق الملكية الفكرية للعامل

```

Legal Fields Check:
☐ Employee ID/Passport present

Jordanian Law Compliance:
☐ Annual leave = 14 days minimum (Article 35)
☐ Sick leave = 14 days (Article 44)
☐ Probation period <= 90 days (Article 35)
☐ Notice period >= 1 month (Article 23)
☐ Social security mentioned (Article 33)
☐ Termination clauses per Article 28
☐ End-of-service gratuity mentioned (Article 32)

Warning Flags:
🚩 If salary < minimum wage → WARN user
🚩 If working hours > 8 → ADD overtime clause
🚩 If probation > 90 → ERROR (not allowed)
🚩 If notice period < 1 month → ERROR (illegal)
🚩 If employee is woman in 6th month of pregnancy → WARN cannot terminate (Article 27)

Pass all checks → Generate contract
Fail checks → Show error + suggest corrections
